What it does

Record and replay
Your clicks, keys, scrolls and mouse moves are saved with their exact timing. Replay at 1x or faster, for a set number of loops or forever.
Stays attached to Roblox
Clicks are saved relative to the game window, so a macro still lands if you move or resize it. Input only goes out while Roblox is focused.
Live view
Watch the game inside Axiom’s overview, next to a run timer, loop count and average loop time.
Auto-rejoin
If Roblox closes while a macro runs, Axiom relaunches it into your game and can restart the macro for you.
Discord updates
Get a message when a run starts, progresses and finishes, plus a screenshot of your rewards screen on every loop.
Share macros
Save a macro as a file, copy a code, or post it to a Discord channel. Imported macros are checked before they are added.
Six color themes
Crimson, blue, mono, black, pink and purple, and F1 to F12 hotkeys that you can remap.

Questions

Can my Roblox account get banned?

Maybe. Axiom only sends mouse and keyboard input, and never reads or changes the game’s memory, which is the lowest-risk way to automate. Roblox and individual games can still treat automation as cheating, so use it at your own risk.

Does it work for any game?

It records and replays input in the Roblox window, so it works in any experience. The rejoin and screenshot features need a game link and a rewards area that you set once.

Why does Windows warn me when I open it?

The app is new and not yet code-signed, so SmartScreen shows “Unknown publisher”. The download page explains how to continue.
